- **INV-CLI-reference-generated-from-command-tree** `docs/cli-reference.md` and `docs/man/keyorix.1` are generated from the cobra command tree by `keyorix docs markdown|man` (`cli/internal/clidocs`), never edited by hand, and byte-identical to what the binary prints: changing any command, flag, example or help text means running `make -C cli docs`. The output is a pure function of the tree (no dates, versions, paths; no dependence on which commands have run: `-h/--help` is not listed and the synopsis is built by `useLine`, not cobra's `UseLine`). Why: CLI-UX-1 item 4 (hand-written CLI docs had drifted: `REMOTE_CLI_TROUBLESHOOTING.md` listed `config status` and `auth status`, which do not exist). Guard: `cli/cmd/docs_test.go:TestCLIReferenceIsFresh` (red when stale), `TestCLIReferenceCoversEveryCommand`, `TestCLIReferenceHasNoMachineSpecificText`, `TestShellCompletionScripts` (bash/zsh syntax-checked, fish when installed), `cli/internal/clidocs/clidocs_test.go`, journey `TestJourney_CLIDocsAndCompletion`.
