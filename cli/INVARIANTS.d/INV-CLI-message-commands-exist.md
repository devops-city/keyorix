- **INV-CLI-message-commands-exist** Every command (and flag) that a Go string literal tells an operator to run, written in backticks or single quotes starting with `keyorix` or `keyorix-server admin`, exists in the real command tree of the CLI (`cli/cmd`) or of the server's admin tree (`server/admin`). A message that says "run `keyorix encryption rotate --confirm`" is a promise: it named commands that did not exist for months (found by DOCS-PILOT-1). Guard: `cli/cmd/cmdrefs_guard_test.go:TestEveryCommandNamedInAMessageExists` and `server/admin/cmdrefs_guard_test.go:TestEveryServerCommandNamedInAMessageExists`, one checker in two byte-identical copies (`cmdrefs_check_test.go`; `TestCmdRefsCheckerCopiesAreIdentical` fails on drift). Does NOT see: commands in comments, in unquoted prose, in test files, assembled by concatenation or `fmt` verbs, or in docs/web copy (web copy has `web/src/test/cliCommandsGuard.test.ts`); only the first lowercase word run is checked as a path, a `<placeholder>`, `$VAR`, UPPERCASE or dotted word ends it, and short flags are not checked. Real deviations go in `cmdRefsKnownStale` with a reason (`keyorix-server admin version` is answered before cobra).
