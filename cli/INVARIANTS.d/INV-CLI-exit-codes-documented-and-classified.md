- **INV-CLI-exit-codes-documented-and-classified** The process exit code says why the CLI failed (0 ok, 1 refused/failed, 2 usage, 3 not logged in / session rejected, 4 permission denied, 5 not found, 6 server unreachable or TLS refused), the table is printed by `keyorix --help`, and a failure prints one readable message with a next step: no Go error chain (`dial tcp ...`), stack trace or raw HTTP body. Codes come from `apiError`/`httpStatusError` (HTTP status), `usageErrorf` (mistakes in flags/arguments), `apiclient.DescribeTransportError` (no answer from the server) and `Run` (panic -> one-line internal error). Why: CLI-UX-1; before it every failure exited 1 and `keyorix secret lst` exited 0.
