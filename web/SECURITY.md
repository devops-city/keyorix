# Security Policy

The Keyorix vulnerability disclosure policy is maintained in one place:
**[`/SECURITY.md`](../SECURITY.md)** (reporting channel, response targets, scope,
safe harbour, advisories and patch releases, supported versions).

To report a vulnerability in the web dashboard, use that policy. Do not open a
public issue. The reporting address is `security@keyorix.com`, or GitHub private
vulnerability reporting on this repository.

This file used to carry a separate policy with different contact details and
response times. It was removed on purpose, so that there is one set of
commitments to keep.
