## 🌐 Fresh-Install / Real-Backend E2E Smoke

Unlike the mock-JWT handler/integration tests above, this suite boots a **real
`keyorix-server` binary** against a **real database** (SQLite or PostgreSQL),
bootstraps it exactly the way an operator would (`admin init` →
`admin encryption init` → `admin migrate` → boot → `POST /system/init`), and
then drives every feature group through real HTTP calls and the real CLI
binary. It exists to catch the class of bug the mocked tests structurally
cannot see: missing `AutoMigrate` tables, dialect-specific SQL (`LIKE` vs
`ILIKE`, `GROUP BY` strictness), and unclassified 500s that only appear when
a real storage layer returns a real error.

Source lives under `scripts/e2e/` (Go, build tag `e2e` — excluded from the
default `go test ./...` inner loop) and `web/e2e/real/` (Playwright specs
against the real backend, kept separate from the mocked specs under
`web/e2e/` via `testIgnore`).

### What it covers

- **Route inventory** (`scripts/e2e/routes.json`, generated by
  `server/http/route_inventory_test.go` from `server/http/router.go` itself —
  not hand-maintained): every registered route, its feature group, and any
  permission gate.
- **API smoke** (`scripts/e2e/api_smoke_test.go`): create/read/list/update/
  delete across every feature group (secrets, projects, users, roles,
  groups, sharing, audit, notifications, compliance, settings, and more),
  asserting no unhandled 5xx, every route hit or explicitly skip-listed with
  a reason, and a `verify-audit` chain that is still VALID at the end. Runs
  against both SQLite and PostgreSQL.
- **Upgrade path** (`scripts/e2e/upgrade_test.go`): a database created and
  populated by the previous release binary, then started against `HEAD`, to
  catch migration gaps that a fresh-install run alone would never exercise.
- **Real-backend web** (`web/e2e/real/pages.spec.ts`): Playwright driving the
  real UI against the real backend, asserting no console errors and no
  failed network requests, across secrets/projects/users/roles/groups/
  sharing/audit/notifications/compliance/settings pages.
- **Demo journeys** (`web/e2e/demo/*.spec.ts`, `make e2e-web-demo`): the demo
  catalogue as eight Playwright specs on the same harness (one fresh server
  per file): login and forced MFA enrolment, secret create/rotate/history/
  rollback, share with expiry and revoke, machine identity and token, audit
  search, compliance evidence export and verify, an anomaly after a trigger,
  and break-glass in the audit log. Kept out of `web/e2e/real/` on purpose, so
  the pull_request profile's `web-e2e-real-smoke` job does not run them. They
  are meant for the full CI profile only (merge queue, push to `main`,
  `ci:full`); that needs its own job in `ci.yml`, which is not part of this
  change. Until then, run them with `make e2e-web-demo`. The anomaly journey
  waits for the detector's first pass (about a minute).

### Running it

```bash
# SQLite leg (no external dependencies)
make e2e-smoke

# PostgreSQL leg (requires KEYORIX_TEST_PG_DSN, e.g. a local
# `docker run postgres:16` instance — see the target's own comment
# in the Makefile for the exact invocation)
make e2e-smoke-postgres

# Upgrade-path leg (downloads the previous release binary from
# GitHub Releases, seeds a DB with it, then boots HEAD against it)
make e2e-smoke-upgrade

# Real-backend Playwright suite (builds the server, provisions and
# boots it, seeds a project + secret, then runs Playwright against
# the real UI)
make e2e-web-smoke

# Everything except the PostgreSQL leg (which needs a DSN and isn't
# wired into the default target for that reason)
make e2e-smoke-all
```

Each Go leg is a standalone `go test -tags e2e ./scripts/e2e/...` invocation
(see the Makefile for the exact `-run` filter per target), so it can also be
run directly, or with `-v` for full per-call tracing.

### Design notes

- The Go smoke driver's HTTP client distinguishes a **hard failure** (any
  5xx — always a bug, aborts the run) from a **soft mismatch** (an
  unexpected-but-non-5xx status — recorded via `t.Errorf` and the run
  continues) specifically so one run surfaces every status-code issue in
  the feature matrix instead of stopping at the first one.
- Route coverage is enforced both ways: every route in
  `scripts/e2e/routes.json` must be exercised by the smoke driver OR appear
  in its skip-list with a reason, AND every skip-list entry must still
  resolve to a real route — catching both an accidentally-untested route and
  a stale skip-list entry left behind after a route was removed.
- This suite is intentionally **not** part of the default `go test ./...` or
  `make test` inner loop — it builds and boots a real binary per leg, which
  is too slow for the fast local/PR loop. It's meant for a scheduled/nightly
  run (see "NEEDS ANDREI" in the SESSION-I report for a proposed CI job) or
  for a deliberate pre-release check.

## 🚨 Troubleshooting

### Common Issues

**Tests fail with "address already in use"**
```bash
# Check for processes using test ports
lsof -i :8080
lsof -i :9090

# Kill conflicting processes
kill -9 <PID>
```

**Race condition detected**
```bash
# Run with race detection
go test -race ./...

# Fix any reported race conditions
```

**Coverage too low**
```bash
# Generate detailed coverage report
go test -coverprofile=coverage.out ./...
go tool cover -func=coverage.out

# Identify untested code
go tool cover -html=coverage.out
```

**Benchmark performance issues**
```bash
# Run benchmarks with memory profiling
go test -bench=. -benchmem -memprofile=mem.prof ./...

# Analyze memory usage
go tool pprof mem.prof
```

## 📝 Writing New Tests

### Test Template

```go
func TestNewFeature(t *testing.T) {
    tests := []struct {
        name           string
        input          interface{}
        expectedOutput interface{}
        expectedError  string
    }{
        {
            name:           "successful case",
            input:          validInput,
            expectedOutput: expectedResult,
            expectedError:  "",
        },
        {
            name:          "error case",
            input:         invalidInput,
            expectedError: "expected error message",
        },
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            // Test implementation
            result, err := functionUnderTest(tt.input)
            
            if tt.expectedError != "" {
                assert.Error(t, err)
                assert.Contains(t, err.Error(), tt.expectedError)
            } else {
                assert.NoError(t, err)
                assert.Equal(t, tt.expectedOutput, result)
            }
        })
    }
}
```
