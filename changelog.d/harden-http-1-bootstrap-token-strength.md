### Security
- **BREAKING: a pinned `KEYORIX_BOOTSTRAP_TOKEN` must be at least 32 characters.** The server refuses to start when `KEYORIX_BOOTSTRAP_TOKEN` (or `KEYORIX_BOOTSTRAP_TOKEN_FILE`) holds fewer than 32 characters: `KEYORIX_BOOTSTRAP_TOKEN too short (min 32 characters): generate one with: openssl rand -hex 32`. The token authorises claiming the first admin over `POST /system/init`, so a short phrase on a fresh, reachable server was a guessable admin seizure. Unset is unchanged (the server generates a 256-bit token). QUICK_START and the smoke / web-e2e / release-QA scripts now generate the token with `openssl rand -hex 32`. See docs/UPGRADING.md §6g.
