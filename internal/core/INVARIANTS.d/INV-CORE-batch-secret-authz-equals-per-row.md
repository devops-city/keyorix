- **INV-CORE-batch-secret-authz-equals-per-row** A list view that must know, for each secret on its page, whether the caller may read it decides the page with `AuthorizeSecretsBatch`, never with `AuthorizeSecret` in a loop, and the batch returns for every secret exactly what `AuthorizeSecret(ctx, user, secret, perm)` returns for a human user: same PAT restriction, ACL grants (own and folder-ancestor, depth-capped, honoured only while the grantee is a live member of the granting node's project, a deleted ancestor erroring into a denial), role decision at the secret's project/environment (direct and via live groups, expired grants, deleted projects/environments/groups, admin bypass), and share term (active direct share, else group share through a group the user is in at that project, only for a live project member, a write share never elevating an unnamed action), and the same share-elevation records.
